# SSL/TLS Client scanner
Utility to scan a client (not a server) for SSL/TLS security issues.

# Quickstart

  - Download [this archive](https://github.com/ondrejsmetak/ssl-tls-client-scanner/raw/master/proxy.zip) and unzip it.
  - Then consult following [user manual](https://github.com/ondrejsmetak/ssl-tls-client-scanner/blob/master/manual.pdf).

# More info
  - You can read [this chapter](https://github.com/ondrejsmetak/ssl-tls-client-scanner/blob/master/info.pdf) of my thesis, which is focused on automated testing of SSL/TLS communication.
  - You may be also interested in [SSL/TLS Server scanner](https://github.com/fredomgc/ssl-tls-server-scanner).
